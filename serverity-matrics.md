Low Severity
Criteria: Isolated event, no data exfiltration, system performance unaffected.
Example: A single user receives a phishing email but does not click any links.
Medium Serverity
Criteria: Single system compromised, minor business disruption, no critical data lost.
Example: A workstation is infected with adware or non-spreading malware.
High Serverity
Criteria systems offline, widespread network infection, confirmed data breach.
Example: A ransomware attack targeting core database or domain controllers.
